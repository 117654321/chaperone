# e1

## 干什么用的

E1 掩码语言模型，做序列预测。

## 什么时候用它

从部分序列推全长，或做序列补全。

## 基本信息

- **一句话**：E1 masked language model for sequence prediction
- **执行方式**：容器（`e1`）
- **需要上游输入**：是
- **容器入口**：`python /home/user/software/chaperone/src/blocks/scripts/run_e1.py`

## 怎么调用

```python
from chaperone import ExecutionEngine, init_cli
init_cli()
engine = ExecutionEngine(rundir="out")
h = engine.run("e1", data=upstream_handler, <参数>=<值>)
```

参数三种传法，优先级从高到低：

| 方式 | 写法 | 用途 |
|---|---|---|
| 命令行 | `--e1.参数名=值` | 临时试，不改代码 |
| 配置文件 | `--config=my.yaml`（`参数名: 值`，按 block 名分组） | 批量改、存版本 |
| 脚本 kwargs | `engine.run("e1", 参数名=值)` | 最常用 |

## 全部参数

| 参数 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `store` | `Literal['none', 'catcif']` | `"none"` | 编译后合并输出。``'none'`` 不存储；``'catcif'`` 写成一个拼接的 CIF 归档。 |
| `store_cleanup` | `bool` | `false` | ``store='catcif'`` 时，文件并入归档后删除沙盒里的输出文件。其他情况忽略。 |
| `command_template` | `Optional[List[str]]` | `None` | — |
| `cloud` | `bool` | `false` | — |
| `model_name` | `Union[Literal['150m', '300m', '600m'], str]` | `"150m"` | 模型规模（150m、300m、600m）或完整 HuggingFace 路径 |
| `max_batch_tokens` | `int` | `65536` | 单次前向的最大批 token 数 |
| `save_masked_positions_only` | `bool` | `false` | 是否只为被遮罩位置保存 logits/嵌入 |
| `fields_to_save` | `list[str]` | `['logits', 'token_embeddings', 'mean_token_embeddings']` | 输出 safetensors 中保存的字段 |
| `context_fasta` | `str \| None` | `None` | 检索增强预测用的上下文 FASTA 路径（可选） |
| `cache_dir` | `str` | _运行时计算_ | HuggingFace 模型缓存，直接挂进容器 |

## 由脚本提供的参数

这些不写进参数表，运行时由引擎或你的脚本传入：

| 参数 | 谁提供 |
|---|---|
| `data` | 引擎：`engine.run(..., data=上游handler)` |
| `name` | 可选，默认就是 block 名；同类型用两次才需要改名 |
